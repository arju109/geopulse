# GeoPulse Project Overview 
GeoPulse is a Hyperlocal Retail Analytics project. 
## Objective
To analyse customer mobility patterns and understand store visit behaviour. 
## Key Technologies
- Python - Snowflake - Apache Spark and Sedona - dbt - Apache Airflow - React and Kepler.gl
   ## Expected Outcome
   To identify store visitor trends and analyse customer movement between stores.
